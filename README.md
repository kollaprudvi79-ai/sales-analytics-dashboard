# Sales Analytics Dashboard — Data Analyst Project

> **Problem:** E-commerce leadership can't answer basic questions: Which categories are actually profitable? Is discounting working? Where should we invest?

> **Solution:** Interactive KPI dashboard + Python EDA uncovering that Electronics drives 42% of revenue but only 28% of profit — discount-heavy and margin-destroying.

**Live dashboard:** https://kollaprudvi79-ai.github.io/sales-analytics-dashboard/

## 📊 Key Findings

1. **Electronics paradox:** 42% of revenue, 28% of profit — discounts above 20% destroy margin
2. **Q4 spike is real:** November revenue 2.3× monthly average — stock accordingly
3. **West region wins:** 34% repeat-purchase rate (highest) — replicate their playbook
4. **Discount cliff:** Net profit turns negative past 25% discount — cap at 20%
